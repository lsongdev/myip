# Service icons

Local copies of the services' own favicons, used to identify connectivity probes. Loading the UI icons does not contact the probe hosts.

- ByteDance: favicon embedded in https://www.bytedance.com/ (PNG data URL).
- Bilibili: https://www.bilibili.com/favicon.ico
- WeChat: https://res.wx.qq.com/a/wx_fed/assets/res/NTI4MWU5.ico (PNG, linked by https://weixin.qq.com/).
- Taobao: https://www.taobao.com/favicon.ico
- GitHub: https://github.com/favicon.ico
- jsDelivr: https://www.jsdelivr.com/favicon.ico
- Cloudflare: https://www.cloudflare.com/favicon.ico (PNG).
- YouTube: https://www.youtube.com/favicon.ico
